# 🏙️ City Simulation Sandbox — AgentSandbox
> **Primary Function:** Virtual multi‑region test environment for agent planning and scenario testing

## 📌 Purpose
Provide a risk‑free virtual environment where agents can design, test, and evaluate infrastructure, logistics, emergency responses, and policies — without affecting real‑world systems.

## ✨ Key Features
- **Multi‑Region City Models:** Simulate cities with realistic demographics, geography, and infrastructure
- **Scenario Library:** Prebuilt scenarios — natural disasters, energy shortages, transit planning, population shifts
- **What‑If Analysis:** Compare multiple agent strategies side‑by‑side
- **Long‑Term Simulation:** Fast‑forward months or years to observe policy outcomes
- **Resource Metrics:** Track cost, time, energy usage, and impact across all simulated regions

## 🏗️ Simulation Dimensions
| Category | Examples |
|---|---|
| **Demographics** | Population density, age distribution, growth rate |
| **Infrastructure** | Roads, power grids, water supply, hospitals |
| **Environment** | Weather patterns, terrain, seasonal changes |
| **Economy** | Budget, currency, resource costs |
| **Events** | Emergencies, seasonal peaks, infrastructure failures |

## 🔄 Typical Workflow
1. Select or create target region/city profile
2. Define simulation parameters and timeframe
3. Agent proposes plan → Simulator executes → Results analyzed
4. Compare against baseline or alternative proposals
5. Refine and re‑run until satisfied
