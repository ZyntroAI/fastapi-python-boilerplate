05 · Token Layer 1

OIDC Zero-Touch — ไม่เก็บ long-lived credentials

  • permissions: id-token: write — GitHub ออก short-lived JWT ให้เองต่อ job
  • aws-actions/configure-aws-credentials@v4 + role-to-assume
  • Token อายุ 1 ชั่วโมง — auto-rotate ทุก job, ไม่มี secret ให้ leak
  • Audit log ชัดเจนว่า workflow ไหนใช้ token
  • ถ้า token หลุด → expire เองภายใน 1 ชม.

07 · Token Layer 3

Self-Healing Patterns

Retry + Backoff

3 ครั้ง, รอ 2^n วินาที — จัดการความล้มเหลวชั่วคราวโดยไม่ต้องมีคน intervene

Auto-Refresh on 401/403

เจอ token หมดอายุ → refresh → gh secret set → retry อัตโนมัติ

Health Check

ทุก 6 ชม. ตรวจ token ทั้งหมด → แจ้ง Slack ถ้าล้ม ก่อน workflow จริงจะพัง

  • Rotation cadence: Cloud = ทุก job (OIDC) · GitLab = 30–90 วัน · OAuth = 90 วัน · API Key = 30 วัน · PAT = 90 วัน

08 · Actions hardening

Security First — 5 ข้อก่อน merge workflow

  • Pin actions to full SHA — กัน tag hijacking supply chain attack (actions/checkout@11bd719…)
  • Least privilege — ตั้ง org default เป็น read-only, permissions: {} แล้ว grant เฉพาะที่จำเป็น
  • กัน script injection — ห้ามใช้ ${{ github.* }} ใน run: โดยตรง ให้ส่งผ่าน env:
  • OIDC + Environment protection rules — required reviewers, deployment branches
  • Secret scanning + Push protection — เปิดใน Organization Settings
