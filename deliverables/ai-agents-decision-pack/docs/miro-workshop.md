# AI Agents Evaluation — Miro Workshop Outline

45–60 min structured session to align a team before committing to an AI agent.

## Prep
- Everyone reviews `README.md` (comparison matrix + rubric) and fills the Notion
  table for their 1-week trial first.
- Board columns: Criteria wall · Agent columns · Weighting · Verdict.

## Agenda (45 min)
1. **Goals & guardrails (5m)** — agree the security bar (sandbox/approval-gated
   exec, no secret leakage) and the stack-fit requirement. Record on a sticky.
2. **Individual scoring (10m)** — silent: score each shortlisted agent 1–5 on
   the rubric (Security / Capability / Efficiency / Cost / Stack fit). Post to
   the agent columns.
3. **Weighting (5m)** — agree weights (e.g., Security 30%). Multiply and total.
4. **Debate the top 2–3 (15m)** — discuss the leaders against real trial
   evidence (speed, multi-file edits, sandbox behavior, cost). Vote.
5. **Decision & next steps (10m)** — pick Adopt / Trial / Watch. Assign: who
   runs a deeper trial, who owns the Notion scores, re-check date.

## Facilitation notes
- Security is non-negotiable: any agent that reads/echoes secrets outside an
  approved flow is out regardless of score.
- Capture dissent on stickies — a "Watch" list with reasons is valid output.
