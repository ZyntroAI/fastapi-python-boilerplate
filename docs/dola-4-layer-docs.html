🧠 Layer 1: Agent Skills

  • • skill-creator — สร้างทักษะใหม่
  • • filesystem-memory — หน่วยความจำยาวนาน
  • • best-practices — กฎ React/Vercel/Supabase

⚙️ Layer 2: Middlewares

  • • Logging/Tracing/Request-ID
  • • Timeout + Retry + Circuit-Breaker
  • • AuthN + Idempotency + Audit

🧪 Layer 3: Mock APIs

  • • MSW / Mockoon — ทดสอบแบบออฟไลน์
  • • json-server / Prism — ตามสเปก OpenAPI
  • • Faker — ข้อมูลเทียมสมจริง

🛡️ Layer 4: Pre-commit

  • • Prettier + ESLint + Ruff — จัดรูปแบบ
  • • Type-check + Test + Build — ตรวจสอบ
  • • gitleaks + Husky + lint-staged — ความปลอดภัย

⚙️ GitHub Action — dola-skills.yml

name: Dola 4-Layer Workflow
on: [push, pull_request]
jobs:
  layer1-skills:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: python dola-obsidian-client-v2.py --skill filesystem-memory
  layer2-middleware:
    needs: layer1-skills
    run: python scripts/safety-check.py --timeout --retry
  layer3-mock:
    needs: layer2-middleware
    run: npx msw init ./public
  layer4-precommit:
    needs: layer3-mock
    run: npx lint-staged && npm run test && npx gitleaks detect
