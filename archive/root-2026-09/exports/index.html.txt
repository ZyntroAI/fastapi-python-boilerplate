<section>
    <h2>🚀 Overview</h2>
    <p>A <strong>production‑ready FastAPI boilerplate</strong> integrating:</p>
    <ul>
        <li>🧩 <strong>LangGraph AI Agent</strong> — query SQL databases using natural language</li>
        <li>💳 <strong>Stripe Payment Integration</strong> — secure, scalable payment flow</li>
        <li>⚙️ <strong>Helm + Kubernetes CI/CD</strong> — automated deployment and scaling</li>
        <li>🌐 <strong>Traefik Routing</strong> — seamless microservice orchestration</li>
    </ul>

    <h2>⚙️ Getting Started</h2>
    <h3>Requirements</h3>
    <ul>
        <li>Python 3.11+</li>
        <li>Docker Desktop 4.43+ or Docker Engine</li>
        <li>Docker Compose 2.38.1+ (Linux)</li>
        <li>Optional GPU for local inference</li>
    </ul>

    <h3>Quick Start</h3>
<pre>git clone https://github.com/ZyntroAI/fastapi-python-boilerplate.git
cd fastapi-python-boilerplate
docker compose up</pre>

    <h2>🔑 Environment Variables</h2>
    <table>
        <thead><tr><th>Variable</th><th>Description</th><th>Example</th></tr></thead>
        <tbody>
            <tr><td><code>DATABASE_URL</code></td><td>PostgreSQL connection string</td><td><code>postgresql://user:pass@db:5432/chinook</code></td></tr>
            <tr><td><code>OPENAI_API_KEY</code></td><td>API key for OpenAI inference</td><td><code>sk-xxxx</code></td></tr>
            <tr><td><code>STRIPE_SECRET_KEY</code></td><td>Stripe secret key</td><td><code>sk_live_xxxx</code></td></tr>
            <tr><td><code>STRIPE_PUBLIC_KEY</code></td><td>Stripe publishable key</td><td><code>pk_live_xxxx</code></td></tr>
            <tr><td><code>APP_ENV</code></td><td>Environment mode</td><td><code>development</code> / <code>production</code></td></tr>
        </tbody>
    </table>
    <p class="note">Store secrets in <code>.env</code> or <code>secret.*</code> files. <strong>Never commit secrets to Git.</strong></p>

    <h2>🧠 Inference Options</h2>
    <p><strong>Default:</strong> Local Docker model runner.</p>
    <p><strong>Switch to OpenAI:</strong></p>
<pre>echo "sk-..." > secret.openai-api-key
docker compose down -v
docker compose -f compose.yaml -f compose.openai.yaml up</pre>

    <h2>🧪 Testing Guide</h2>
    <p>Run unit tests:</p>
<pre>pytest tests/</pre>
    <p>Run with coverage report:</p>
<pre>pytest --cov=app --cov-report=xml tests/</pre>
    <p>Integration tests (requires containers running):</p>
<pre>docker compose exec backend pytest tests/integration</pre>

    <div class="note">
        <strong>Codecov Tip:</strong> Add this to your CI workflow to automatically upload coverage:
<pre>- name: Upload Coverage to Codecov
  uses: codecov/codecov-action@v4
  with:
    files: ./coverage.xml</pre>
    </div>

    <h2>☸️ Kubernetes Deployment (Helm)</h2>
    <h3>Install Helm Chart</h3>
<pre>helm install fastapi-boilerplate ./helm</pre>
    <h3>Upgrade Release</h3>
<pre>helm upgrade fastapi-boilerplate ./helm</pre>

    <h3>values.yaml Highlights</h3>
<pre>replicaCount: 3
image:
  repository: zyntroai/fastapi-boilerplate
  tag: latest
ingress:
  enabled: true
  hosts:
    - host: fastapi.local
      paths: ["/"]
resources:
  limits:
    cpu: 500m
    memory: 512Mi</pre>
