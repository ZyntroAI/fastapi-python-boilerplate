### 📄 `docs/STRIPE_ENTITLEMENTS.md`
```markdown
# 💰 Stripe Billing Entitlements — Integration Guide

## 🎯 What Are Entitlements?
> **Entitlements = Map Features → Products → Subscriptions** — control access without changing code.

## How It Works
```
Stripe Dashboard ──Features──→ Products ──Subscriptions──→ Customers
       │                                                        │
       ▼                                                        ▼
  Define Features                                        Stripe Webhooks:
  • API Access                                         • Grant Access ✅
  • AI Assistant                                       • Revoke Access ❌
  • Premium Support                                     • What Features?
  • Extended Retention                                  • Until When?
```

## Step-by-Step Setup
1. **Create Features** in Stripe Dashboard → Product Catalog → Features
   - **Name:** Display name
   - **Lookup Key:** Unique identifier (e.g., `ai_assistant`) — use THIS in code!
2. **Attach Features to Products** → Each plan inherits its features
3. **Check in Code** → Query Stripe API: "What features does this customer have?"
4. **Webhooks** → `customer.subscription.updated` → Auto-provision/revoke

## Code Example
```python
import stripe
stripe.api_key = "sk_..."

def has_entitlement(customer_id: str, feature_key: str) -> bool:
    entitlements = stripe.entitlements.ActiveEntitlement.list(
        customer=customer_id, limit=100
    )
    return any(e.lookup_key == feature_key for e in entitlements.data)

# Usage
if has_entitlement("cus_xxx", "ai_assistant"):
    enable_ai_assistant()
else:
    show_upgrade_prompt()
```

## Key Benefits
- ✅ **Change features → no code deploy** — update in Dashboard only
- ✅ **Auto-provisioning** — Webhooks notify your backend
- ✅ **Cleaner code** — `if has_feature("priority_support")`
- ✅ **Syncs automatically** with subscription changes

## CLI / Plugin
```bash
npm install -g @stripe/cli
stripe agent setup
claude plugin install stripe@claude-plugins-official
```

### 📄 `infrastructure/helm/payments-platform/values.yaml`
```yaml
# Global — applies to ALL subcharts
global:
  imagePullSecrets: []
  env:
    LOG_LEVEL: info

# API Service
api:
  image:
    repository: your-registry/api
    tag: v1.2.3
  replicaCount: 2
  service:
    type: ClusterIP
    port: 8080
  env:
    DATABASE_URL: "postgresql://postgres:password@payments-postgres:5432/payments"

# Skip-Payment CronJob
skip-payment:
  image:
    repository: your-registry/skip-payment
    tag: latest
  cron:
    schedule: "0 0 * * *"  # Daily at midnight UTC
  env:
    DB_URL: "postgresql://postgres:password@payments-postgres:5432/payments"
    # SUPABASE_KEY: managed via Kubernetes Secrets — NOT here!

# PostgreSQL (Bitnami)
postgres:
  fullnameOverride: payments-postgres
  auth:
    username: postgres
    password: password  # ⚠️ Use Secrets in production!
    database: payments
  primary:
    persistence:
      enabled: true
      size: 8Gi
```
