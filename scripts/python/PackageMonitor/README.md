# 📦 PackageMonitor

Dependency health & security scanner for `package.json` + `package-lock.json`.

## ✅ Checks
- ✅ Missing/corrupted files
- ✅ Loose/wildcard versions
- ✅ package.json ↔ lockfile sync
- ✅ npm audit — security vulnerabilities
- ✅ Outdated dependencies
- ✅ Missing/empty npm scripts

## 🚀 Quick Start
```bash
# Run manually
python scripts/python/PackageMonitor/package_monitor.py

# Output → reports/package-monitor/
