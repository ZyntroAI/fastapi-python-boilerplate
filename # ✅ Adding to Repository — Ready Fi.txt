# 🤖 Claude REST API — Complete Developer Guide
**API Version:** 2026-01-01 · **Models:** Claude 3.5+ · **Base URL:** `https://api.anthropic.com`

## 📋 Overview

The Claude REST API enables you to integrate Claude directly into your applications using standard HTTP requests — no SDK required. This guide covers authentication, endpoints, request/response formats, and best practices.

---

## 🔑 Authentication

### Headers (Required on Every Request)
```http
x-api-key: YOUR_API_KEY_HERE
anthropic-version: 2026-01-01
content-type: application/json
```

> Get your API key from: **console.anthropic.com** → API Keys → Create Key  
> Keep it secure — never commit to code, use environment variables.

## 📤 Core Endpoint: Messages API

### POST `/v1/messages` — Send a Message

```bash
curl https://api.anthropic.com/v1/messages \
  -H "x-api-key: $ANTHROPIC_API_KEY" \
  -H "anthropic-version: 2026-01-01" \
  -H "content-type: application/json" \
  -d '{
    "model": "claude-sonnet-4-6",
    "max_tokens": 1024,
    "messages": [
      {"role": "user", "content": "Hello, Claude"}
    ]
  }'
```

### Request Body Schema
```json
{
  "model": "claude-sonnet-4-6",
  "max_tokens": 1024,
  "messages": [
    {"role": "user" | "assistant", "content": "string | array"}
  ],
  "system": "string",
  "temperature": 0.0,
  "top_p": 1.0,
  "top_k": 40,
  "stop_sequences": [],
  "stream": false,
  "metadata": {"user_id": "string"}
}
```

### Response
```json
{
  "id": "msg_01...",
  "type": "message",
  "role": "assistant",
  "content": [{"type": "text", "text": "Hello! How can I help?"}],
  "model": "claude-sonnet-4-6",
  "stop_reason": "end_turn",
  "usage": {
    "input_tokens": 8,
    "output_tokens": 12
  }
}
```

## 🛠️ Advanced Features

### System Prompt
```json
{
  "model": "claude-sonnet-4-6",
  "system": "You are a helpful assistant. Answer concisely.",
  "messages": [{"role": "user", "content": "Hi"}]
}
```

### Streaming
```json
{"stream": true, ...}
```
→ Server-Sent Events (SSE) stream — `data: { ... }` per chunk.

### Vision (Images)
```json
{
  "messages": [
    {
      "role": "user",
      "content": [
        {"type": "image", "source": {
          "type": "base64",
          "media_type": "image/png",
          "data": "iVBORw0KGgo..."
        }},
        {"type": "text", "text": "Describe this image"}
      ]
    }
  ]
}
```

### Tool Use / Function Calling
```json
{
  "tools": [{
    "name": "get_weather",
    "description": "Get weather forecast",
    "input_schema": {
      "type": "object",
      "properties": {
        "city": {"type": "string"}
      },
      "required": ["city"]
    }
  }],
  "tool_choice": "auto"
}
```

### Prompt Caching
Include a **system prompt marked as cacheable** — subsequent calls reuse it at ~10% cost:
```json
{
  "system": [
    {"type": "text", "text": "LONG SYSTEM PROMPT...", "cache_control": {"type": "ephemeral"}}
  ]
}
```

### Structured Outputs
```json
{
  "response_format": {
    "type": "json_schema",
    "schema": {
      "type": "object",
      "properties": {
        "answer": {"type": "string"},
        "confidence": {"type": "number"}
      }
    }
  }
}
```

## 📊 Token Usage & Cost

- **Input Tokens:** Your prompts (system + messages)
- **Output Tokens:** Claude's responses
- **Cache Read:** ~10% of input cost
- **Pricing:** See **console.anthropic.com/pricing**

## ⚠️ Error Handling

| Status | Meaning | Action |
|---|---|---|
| `400` | Invalid request | Check params/model |
| `401` | Unauthorized | Check API key |
| `403` | Forbidden | Key permissions / region |
| `429` | Rate limit | Retry with backoff |
| `5xx` | Server error | Retry later |

**Rate Limit Headers:**
```http
x-ratelimit-limit-requests: 50
x-ratelimit-remaining-requests: 45
retry-after: 1
```

## 🐍 Python Example (Raw Requests — No SDK)
```python
import os
import requests

API_KEY = os.getenv("ANTHROPIC_API_KEY")
BASE_URL = "https://api.anthropic.com"

headers = {
    "x-api-key": API_KEY,
    "anthropic-version": "2026-01-01",
    "content-type": "application/json"
}

payload = {
    "model": "claude-sonnet-4-6",
    "max_tokens": 1024,
    "messages": [{"role": "user", "content": "Hello, Claude"}]
}

resp = requests.post(
    f"{BASE_URL}/v1/messages",
    headers=headers,
    json=payload,
    timeout=60
)
resp.raise_for_status()
data = resp.json()

print(data["content"][0]["text"])
print(f"Tokens: {data['usage']}")
```

## ✅ Best Practices
- ✅ Use environment variables for API keys — never hardcode
- ✅ Set reasonable `max_tokens` — avoid paying for unused output
- ✅ Use **Prompt Caching** for long system prompts
- ✅ Implement **exponential backoff** on 429 errors
- ✅ Validate inputs — Claude pays per token
- ✅ Use **Sonnet** for production — best balance of speed/cost
- ✅ Store `id` and `usage` from responses for observability

## 📄 File 2: `app/claude_client.py` — Production Python Client

```python
"""
🤖 Claude REST API Client — Production Ready
Path: app/claude_client.py
Base URL: https://api.anthropic.com
API Version: 2026-01-01
"""

import os
import json
import httpx
from typing import List, Dict, Any, Optional, AsyncGenerator
from dotenv import load_dotenv

load_dotenv()

class ClaudeClient:
    def __init__(
        self,
        api_key: Optional[str] = None,
        base_url: str = "https://api.anthropic.com",
        api_version: str = "2026-01-01",
        timeout: int = 120
    ):
        self.api_key = api_key or os.getenv("ANTHROPIC_API_KEY")
        if not self.api_key:
            raise ValueError("ANTHROPIC_API_KEY not set")
        
        self.base_url = base_url.rstrip("/")
        self.api_version = api_version
        self.timeout = timeout
        self.headers = {
            "x-api-key": self.api_key,
            "anthropic-version": api_version,
            "content-type": "application/json"
        }

    async def send_message(
        self,
        messages: List[Dict[str, str]],
        model: str = "claude-sonnet-4-6",
        max_tokens: int = 1024,
        system: Optional[str] = None,
        temperature: float = 0.0,
        stream: bool = False,
        tools: Optional[List[Dict]] = None
    ) -> Dict[str, Any]:
        """Send message to Claude API"""
        
        payload = {
            "model": model,
            "max_tokens": max_tokens,
            "messages": messages,
            "temperature": temperature,
            "stream": stream
        }
        
        if system:
            payload["system"] = system
        if tools:
            payload["tools"] = tools

        async with httpx.AsyncClient(timeout=self.timeout) as client:
            resp = await client.post(
                f"{self.base_url}/v1/messages",
                headers=self.headers,
                json=payload
            )
            
            if resp.status_code != 200:
                raise Exception(f"API Error {resp.status_code}: {resp.text}")
            
            return resp.json()

    async def stream_message(
        self,
        messages: List[Dict[str, str]],
        model: str = "claude-sonnet-4-6",
        max_tokens: int = 1024,
        system: Optional[str] = None
    ) -> AsyncGenerator[str, None]:
        """Stream response chunk by chunk"""
        
        payload = {
            "model": model,
            "max_tokens": max_tokens,
            "messages": messages,
            "stream": True
        }
        if system:
            payload["system"] = system

        async with httpx.AsyncClient(timeout=self.timeout) as client:
            async with client.stream(
                "POST",
                f"{self.base_url}/v1/messages",
                headers=self.headers,
                json=payload
            ) as resp:
                async for line in resp.aiter_lines():
                    if line.startswith("data: "):
                        chunk = line[6:]
                        if chunk == "[DONE]":
                            break
                        try:
                            data = json.loads(chunk)
                            if data.get("type") == "content_block_delta":
                                yield data["delta"]["text"]
                        except:
                            pass

    def extract_text(self, response: Dict) -> str:
        """Helper: Get text content from API response"""
        return "".join([
            block["text"]
            for block in response.get("content", [])
            if block["type"] == "text"
        ])


# Example Usage
if __name__ == "__main__":
    import asyncio
    
    async def main():
        claude = ClaudeClient()
        resp = await claude.send_message(
            messages=[{"role": "user", "content": "Hello!"}]
        )
        print(claude.extract_text(resp))
        print(f"Tokens: {resp['usage']}")
    
    asyncio.run(main())
```
