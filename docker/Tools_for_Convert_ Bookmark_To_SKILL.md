Here are the best ones right now, grouped by what you need:

### *1. Turn bookmarks into structured skills / research briefs*
- *x-skill*
  Syncs your X/Twitter bookmark folders into a local SQLite cache, then synthesizes them into research briefs: themes, key voices, actions, signals.
  Workflow: `X Bookmarks → Sync → SQLite Cache → Research Briefs`. Pay once for the API sync, reads/briefs after are free.
- *book-to-skill*
  Point it at PDFs/books you own and it converts them into a "Claude Code skill" — structured notes with frameworks, definitions, takeaways, not raw text. Runs locally so your files aren't uploaded. 6574d958

### *2. Turn bookmarks into searchable knowledge bases*
- *Raindrop.io*
  Import all browser bookmarks via HTML export. Uses Collections instead of folders, full-text search, tags, and 2600+ integrations. Great for organizing and resurfacing later.
- *BrowseWiki*
  Lets you query your saved pages like a database: "What articles about AI did I save last month?" and it returns exact passages + source. Focus is on connected insights and auto relationship mapping.
- *bookmarks-to-obsidian*
  Imports Chrome bookmarks into Obsidian, fetches each URL, and creates structured notes organized by PARA folders. 3727f169c7e74847

### *3. Turn bookmarks into audio/learning*
- *NotebookLM trick*
  Drop 5-10 links into a temporary notebook → hit *Audio Overview*. It makes a 2-host podcast summarizing the highlights. Best way to actually "read" your read-it-later backlog.
- *Recapio*
  AI summarizer + searchable "AI Brain" for bookmarks and YouTube. Includes video-first Q&A with timestamps.
- *Readwise Reader*
  Save links, PDFs, YouTube. Has Ghostreader AI, annotations, and best-in-class highlight exports. d4d8f169

### *4. AI bookmark managers that analyze + summarize*
- *Carekeep + n8n*
  Combines AI content analysis with automation workflows to not just store bookmarks but enhance them.
- *Chrome 'Skills'*
  New Google feature: save any Gemini prompt you reuse as a one-click "Skill". Run it across multiple tabs to summarize, compare specs, etc. 4c61e577
