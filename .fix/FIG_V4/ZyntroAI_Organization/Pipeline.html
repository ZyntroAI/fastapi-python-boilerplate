GitLab CI Pipeline - Best Practice Implementation

Pipeline YAML

stages:
  - lint
  - test
  - security
  - deploy

variables:
  PYTHON_VERSION: "3.11"

lint:
  stage: lint
  image: python:${PYTHON_VERSION}
  script:
    - pip install yamllint
    - yamllint skill.yaml
    - echo "✅ Manifest lint passed"

unit_tests:
  stage: test
  image: python:${PYTHON_VERSION}
  script:
    - pip install pytest mock
    - pytest tests/unit --maxfail=1 --disable-warnings -q
  artifacts:
    paths:
      - tests/reports
    expire_in: 1 week

integration_tests:
  stage: test
  image: python:${PYTHON_VERSION}
  script:
    - pip install pytest requests
    - pytest tests/integration --maxfail=1 --disable-warnings -q

security_scan:
  stage: security
  image: python:${PYTHON_VERSION}
  script:
    - pip install bandit safety
    - bandit -r handlers.py
    - safety check
    - echo "✅ Security scan passed"

deploy_staging:
  stage: deploy
  image: python:${PYTHON_VERSION}
  script:
    - echo "Deploying skill to staging..."
    - fig deploy --env=staging skill.yaml
  environment:
    name: staging

deploy_production:
  stage: deploy
  image: python:${PYTHON_VERSION}
  script:
    - echo "Deploying skill to production..."
    - fig deploy --env=production skill.yaml
  environment:
    name: production
  when: manual
  only:
    - main

Best Practice Highlights

Practice Impact Risk if Ignored
Retry workflow Resilient automation Silent failures, brittle pipelines
Credential hygiene Prevents leaks Compromised repos, revoked tokens
Error handling Predictable recovery Unclear failures, wasted debugging
Observability Measurable reliability Blind spots in CI/CD
Separation of concerns Easier maintenance Coupled, fragile code
