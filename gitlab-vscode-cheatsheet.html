GitLab for VS Code Extension — Quick Reference

✨ Core Features

Area Capabilities
Projects & Work Items Create/view issues, MRs; review/discuss changes; filter/search with tokens; quick actions
AI — GitLab Duo Code Suggestions, Agentic Chat, Software Development Flow (requires Premium/Ultimate + Duo add-on)
CI/CD Pipelines View status, jobs, logs; retry/cancel; validate & preview merged CI config; autocomplete variables
Security SAST scanning, security findings dashboard (Ultimate)
Repository Clone or browse read-only; open files in GitLab UI; compare branches; create snippets/patches

📋 Prerequisites & Setup

  1. Install: From VS Marketplace → search GitLab for VS Code
  2. Authenticate: GitLab: Authenticate → enter instance URL → choose PAT (api scope) or OAuth
  3. Connect project: Clone repo → select project in GitLab sidebar
  4. Duo features: Enable in Settings → Extensions → GitLab → GitLab Duo
⚠️ GitLab version support: Only currently maintained releases get fixes. As of Sep 2026: 19.3, 19.2, 19.1. Duo features require Premium/Ultimate + Duo Pro/Enterprise.

🔧 Key Commands (Command Palette)

  • GitLab: Authenticate — sign in
  • GitLab: Create New Issue / Merge Request
  • GitLab: Search Project Issues / MRs — filter with assignee:, label:, milestone:, etc.
  • GitLab: Validate GitLab CI Config
  • GitLab: Run Remote Scan (SAST)
  • GitLab: Open Remote Repository — browse without cloning
  • GitLab: Export Diagnostics — bundle logs for support (tokens redacted)

🛠 Troubleshooting Quick-Check

  • Auth/keychain errors: Remove account → re-authenticate; or use env vars GITLAB_WORKFLOW_INSTANCE_URL + GITLAB_WORKFLOW_TOKEN
  • Duo unavailable: Check tier + namespace; enable feature flags in Settings; run GitLab: Diagnostics
  • Remote/localhost unreachable: Forward ports or set "gitlab.featureFlags.languageServerWebviews": false
  • Logs: Enable debug mode → View → Output → filter "GitLab"
