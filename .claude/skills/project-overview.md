# FastAPI Python Boilerplate

## Purpose
A production-ready FastAPI backend template with:
- Clean route-based structure
- Pydantic for data validation
- Health check endpoints
- CI/CD via GitHub Actions

## Tech Stack
- Python 3.11+
- FastAPI 0.115+
- Pydantic Settings
- Uvicorn
- pytest for testing
