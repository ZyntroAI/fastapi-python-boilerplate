## 📄 File: `infrastructure/docker-compose.observability.yml`
> 📍 Path: `infrastructure/docker-compose.observability.yml`
> One command → full monitoring stack up locally

```yaml
version: "3.8"

services:
  loki:
    image: grafana/loki:3.0.0
    container_name: claude-loki
    ports:
      - "3100:3100"
    volumes:
      - loki-data:/loki
    command: -config.file=/etc/loki/local-config.yaml
    networks:
      - observability
    restart: unless-stopped

  promtail:
    image: grafana/promtail:3.0.0
    container_name: claude-promtail
    volumes:
      - ../logs:/var/log/app:ro
      - ./promtail-config.yml:/etc/promtail/config.yml:ro
      - promtail-data:/tmp
    command: -config.file=/etc/promtail/config.yml
    networks:
      - observability
    depends_on:
      - loki
    restart: unless-stopped

  grafana:
    image: grafana/grafana:11.1.0
    container_name: claude-grafana
    ports:
      - "3000:3000"
    volumes:
      - grafana-data:/var/lib/grafana
      - ../app/grafana_dashboard.json:/var/lib/grafana/provisioning/dashboards/claude.json:ro
      - ./grafana-provisioning/:/etc/grafana/provisioning:ro
    environment:
      GF_SECURITY_ADMIN_USER: admin
      GF_SECURITY_ADMIN_PASSWORD: admin123
      GF_INSTALL_PLUGINS: grafana-loki-datasource
    networks:
      - observability
    depends_on:
      - loki
    restart: unless-stopped

networks:
  observability:
    driver: bridge

volumes:
  loki-data:
  promtail-data:
  grafana-data:
```

## 📄 File: `infrastructure/grafana-provisioning/datasources.yml`
> Auto-configure Loki datasource on first startup

```yaml
apiVersion: 1

datasources:
  - name: Loki
    type: loki
    access: proxy
    url: http://loki:3100
    isDefault: true
    editable: true
    jsonData:
      maxLines: 1000
      timeout: 60
```

## 📄 File: `infrastructure/grafana-provisioning/dashboards.yml`

providers:

    orgId: 1
    folder: ""
    type: file
    disableDeletion: false
    editable: true

## 📄 Updated: `infrastructure/promtail-config.yml`

  disable_reporting: true

positions:
  filename: /tmp/positions.yaml

  - job_name: claude-api
    static_configs:

## 🚀 How to Start the Stack

```bash
# 1. Go to infrastructure folder
cd infrastructure

# 2. Create logs folder (for Claude JSON logs)
mkdir -p ../logs

# 3. Start everything
docker compose -f docker-compose.observability.yml up -d

# 4. Check status
docker compose -f docker-compose.observability.yml ps

# ✅ Access:
# Grafana → http://localhost:3000  (admin / admin123)
# Loki API → http://localhost:3100
```

### 📊 Verify It Works
```bash
# Run a Claude API call → generates log
curl -X POST http://localhost:8000/claude/chat \
  -H "Content-Type: application/json" \
  -d '{"messages":[{"role":"user","content":"Hi"}]}'

# Check logs appear in Loki
curl "http://localhost:3100/loki/api/v1/query?query={job=%22claude-api%22}"
```

### 📈 Open Dashboard

2. Log in: `admin` / `admin123`
