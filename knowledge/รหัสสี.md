1️⃣ ความเข้าใจเบื้องต้น
 
💡 รหัสสี คือ ภาษาที่ใช้บอกคอมพิวเตอร์ว่าให้แสดงสีอย่างไร 
 
- RGB / Hex = สีแสงสำหรับหน้าจอ (Additive Mixing)
- CMYK = สีหมึกสำหรับพิมพ์ (Subtractive Mixing)
- HSL / OKLCH = คิดตามสี → ความเข้ม → ความสว่าง (เหมือนมนุษย์มากขึ้น)
 
2️⃣ Hexadecimal (#RRGGBB)
 
โครงสร้าง
 
 #RR GG BB  หรือ  #RR GG BB AA  (Alpha) 
 
- RR = Red (00‑FF → 0‑255)
- GG = Green (00‑FF → 0‑255)
- BB = Blue (00‑FF → 0‑255)
- AA = ความโปร่งแสง (00 = โปร่ง, FF = ทึบ) 
- ย่อได้เมื่อตัวซ้ำกัน:  #fff  =  #ffffff  
 
ตัวอย่าง
 
css
  
#ff0000    /* แดงเต็ม */
#00ff00    /* เขียวเต็ม */
#0000ff    /* น้ำเงินเต็ม */
#ffffff    /* ขาว */
#000000    /* ดำ */
#ff573380  /* สีส้มคอรัล + 50% โปร่ง */
 
 
3️⃣ RGB / RGBA
 
โครงสร้าง
 
 rgb(red, green, blue) 
 
- ค่า: 0‑255 หรือเปอร์เซ็นต์
-  rgba(r,g,b,alpha) : alpha = 0‑1 หรือ % 
 
ตัวอย่าง
 
css
  
rgb(255,0,0)
rgb(255, 87, 51)
rgba(255,87,51,0.5)
 
 
✅ เหมาะสำหรับเขียนโปรแกรม ปรับค่าได้ง่าย
❌ ยากที่จะเดาได้ว่าเป็นสีอ่อน/สีจัดทันที
 
4️⃣ HSL / HSLA (Hue • Saturation • Lightness)
 
โครงสร้าง
 
- Hue: 0‑360° (วงล้อสี: 0=แดง,120=เขียว,240=น้ำเงิน)
- Saturation: 0‑100% (0% = เทา,100% = สีจัด)
- Lightness: 0‑100% (0% = ดำ,100% = ขาว,50% = สีเต็ม)
- HSLA: เพิ่ม alpha
 
css
  
hsl(0, 100%, 50%)      /* แดง */
hsl(30, 90%, 55%)      /* สีส้ม */
hsl(240, 80%, 45%)     /* น้ำเงินเข้ม */
hsla(30,90%,55%,0.6)   /* สีส้ม + โปร่ง */
 
 
✅ เหมาะสร้าง Palette เดียวกันได้ง่าย (เปลี่ยน L / S)
⚠️ HSL เดิมไม่ได้สอดคล้องกับความสว่างจริงสำหรับ Accessibility
 
5️⃣ OKLCH (ใหม่สำหรับ CSS)
 
✅ OKLCH = Lightness • Chroma • Hue (แนะนำสำหรับ Design System ใหม่) 
 
- L = ความสว่างจริง
- C = ความอิ่มตัวของสี
- H = มุมสี
 
css
  
oklch(0.62 0.25 30)
oklch(0.9 0.08 30) /* สีอ่อนจากฮิวเดียวกัน */
 
 
✅ ง่ายต่อการทำ Contrast ที่ถูกต้องสำหรับเว็บ
 
6️⃣ CMYK (สำหรับพิมพ์)
 
- Cyan / Magenta / Yellow / Key (Black)
- ไม่เท่ากับ RGB โดยตรง ต้องมี Color Profile เช่น sRGB / CMYK
- ❗ เว็บไซต์ไม่ใช้ CMYK โดยตรง
 
7️⃣ ชื่อสี + ความโปร่งแสง
 
css
  
color: red;
color: coral;
color: transparent;
 
 
⚠️ ชื่อสีมีจำกัด ไม่เหมาะสำหรับระบบสีเต็ม 
 
8️⃣ เครื่องมือที่ควรใช้
 
- 🎨 Coolors / Figma / ColorHunt: สร้าง Palette
- 🧪 WebAIM Contrast Checker: ตรวจความคมชัดสำหรับ Accessibility
- 💻 VS Code / Obsidian: Preview Hex สีได้ผ่าน Plugin
- 📐 Color Converter: แปลง Hex ↔ RGB ↔ HSL
- 🧠 Tip: เลือก Palette โดยใช้ OKLCH ก่อน แล้วแปลงเป็น Hex สำหรับ Legacy
 
9️⃣ กฎสำคัญสำหรับ UI
 
1. Contrast Ratio: ข้อความปกติ ≥ 4.5:1 / ข้อความใหญ่ ≥ 3:1 
2. อย่าเลือกสีตามชื่อเท่านั้น
3. สีบนหน้าจอ ≠ สีพิมพ์
4. ใช้ Design Token เช่น  --color-primary  แทน Hardcode Hex
 
css
  
:root {
  --primary: #ff5733;
  --primary-light: hsl(30,90%,70%);
  --text: #111827;
  --bg: #f9fafb;
}
 
 
5. ทดสอบ Dark Mode + Color Blind Simulation
 
🔟 เส้นทางเรียนรู้ต่อ
 
- ✅ ขั้น 1: เข้าใจ Hex → RGB
- ✅ ขั้น 2: เรียน HSL + ทำ Palette
- ✅ ขั้น 3: เรียน OKLCH + Contrast
- ✅ ขั้น 4: สร้าง Design System สำหรับ Quartz / Next.js
- ✅ ขั้น 5: เรียน Color Theory, Gestalt, Branding
 
🧾 ตารางเปรียบเทียบ
 
รูปแบบ ใช้งานหลัก จุดเด่น จุดอ่อน 
Hex เว็บเดิม สั้น คุ้นเคย ยากปรับความสว่าง 
RGB โปรแกรม / CSS ตรงกับช่องสัญญาณ ยากเดาโทนสี 
HSL Palette เบื้องต้น คิดตามวงล้อสี ความสว่างไม่สมจริง 
OKLCH Design System ใหม่ สอดคล้องกับสายตา ยังต้องเรียนเพิ่ม 
CMYK พิมพ์ เหมาะกับหมึก ไม่แสดงบนเว็บตรง
